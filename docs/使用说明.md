# MediaFlow 使用说明

## 运行方式

Windows 发布包解压后运行 `MediaFlow.exe`。MediaFlow 不需要账号，不连接自建服务器，也不要求配置商业 API。

## 解析和下载

1. 从受支持平台复制公开视频分享链接。
2. 在首页点击“从剪贴板粘贴”，或直接输入链接。
3. 点击“解析链接”，等待标题、作者、封面和时长显示。
4. 如果解析结果提供可用媒体地址，点击“加入下载队列”。
5. 在“下载”页面查看队列、进度、保存位置和错误信息。

下载任务按顺序执行。活动任务可以暂停；继续任务时，MediaFlow 会在服务器支持的情况下使用 HTTP Range 从 `.part` 文件继续。

## 下载目录

- 默认情况下，桌面端保存到系统下载目录下的 `MediaFlow` 文件夹。
- Android 完成文件经 MediaStore 发布到 `Download/MediaFlow/`；iOS 本版未正式验收。
- 可在“设置 → 默认下载目录”中填写自定义目录，例如 `D:\MediaFlowDownloads`。

## YouTube 清晰度与合并

默认按完整生产链可用的最高真实分辨率选择，同分辨率再比较 fps、bitrate，仍可手动选择。兼容 H.264 视频与 AAC 音频会下载后自动合并，History 只展示最终文件。VP9/AV1 高画质不自动转码，最终兼容清晰度可能低于平台最高画质；不承诺所有 4K 内容都输出 4K MP4。

## 本地媒体处理

Windows 与 Android 提供快速原码裁剪、AAC → M4A 直接提取及指定时间 JPEG 抽帧。裁剪起点受关键帧影响，不是帧级精准；抽帧依赖平台/设备 decoder。页面按每项能力显示可用状态和原因，HEVC 不会被整个文件拒绝：已测 Windows 可裁剪/提取 AAC、不能 HEVC 抽帧；已测 Android 设备三项可用。

部分 HDR/Dolby Vision 裁剪可能不完整保留高级动态元数据。处理结果有独立 History；原输入及同名文件不会覆盖。取消不生成成功记录，抽帧可能需等待系统调用收敛，不支持进程重启后续做处理。

Windows 随包 FFmpeg 许可证、来源及替换说明位于 `licenses/ffmpeg/`，对应源码合规 ZIP 是独立配套资产。Android 不包含 FFmpeg。iOS/macOS/Linux Processing 本版未正式支持或验收。

## 本地设置

设置页面支持：

- 深色模式
- 启动时恢复未完成任务
- 默认下载目录
- 应用内下载完成提示
- 自动清理失败的 `.part` 文件
- 清理日志和临时缓存

清理缓存不会删除下载历史、未完成任务或已经下载的媒体文件。

## 日志

日志仅保存在本机应用支持目录，按以下文件分类：

- `parser.log`
- `downloader.log`
- `network.log`
- `error.log`

单个日志文件达到约 2 MB 后自动轮转。可通过设置页面清理日志缓存。

## 常见问题

### 解析失败

平台可能修改页面结构、作品可能已删除，或当前网络无法访问平台。请确认链接有效后重试。

### 下载按钮不可用

当前解析结果没有提供可直接下载的媒体地址。MediaFlow 不会把网页文件误存为视频。

### 下载中断

在下载页面点击“继续”。如果平台地址已经过期，需要返回首页重新解析后创建新任务。

## 使用边界

MediaFlow 只处理用户可以正常访问的公开信息，不绕过登录、付费、地区或权限限制。用户应遵守平台服务条款、版权规则和所在地法律。
