# MediaFlow v0.1.0-beta 发布说明

## 发布定位

这是 MediaFlow 的首个免费公开测试版本，用于验证 Windows 与 Android 上的媒体解析、下载队列、本地持久化和基础 UI。项目不依赖自建服务器、付费 API 或商业服务。

## 主要功能

- Bilibili、抖音公开链接识别与媒体信息展示
- Bilibili `b23.tv` 和抖音 `v.douyin.com` 短分享链接处理
- 多任务顺序下载队列
- 暂停、继续、删除和失败重试
- HTTP Range 断点续传
- 下载历史和设置本地恢复
- Windows 自定义下载目录
- Android 完成文件发布到 `Download/MediaFlow/`
- 本地日志、缓存清理和应用内完成提示
- 跨平台安全文件名与稳定标题 fallback
- 关于页面和 Apache-2.0 开源协议

## 验收状态

- `flutter analyze` 通过
- 52 项自动化测试全部通过
- Windows RC 真实 Bilibili/抖音链接解析、下载和播放验证通过
- Android USB 真机 APK 安装、真实下载、暂停/继续和历史恢复验证通过

## Windows 安装

1. 下载 `MediaFlow-v0.1.0-beta-windows-x64.zip`。
2. 校验同名 `.sha256` 文件中的 SHA256（可选）。
3. 完整解压压缩包，不要只运行压缩包内的 EXE。
4. 运行 `MediaFlow.exe`。
5. 如果提示缺少 MSVC 运行库，请安装免费的 Microsoft Visual C++ Redistributable 2015-2022 x64。

压缩包内包含程序运行目录、`README.md`、`LICENSE`、`USER_GUIDE.md` 和 `RELEASE_INFO.txt`。

## Android 安装

1. 下载正式签名的 `MediaFlow-v0.1.0-beta-android.apk`。
2. 校验同名 `.sha256` 文件中的 SHA256（可选）。
3. 在 Android 设备上允许安装该 APK。
4. 完成文件保存在 `Download/MediaFlow/`，并可通过系统文件管理器和视频播放器访问。

## 已知限制

- 仅支持平台公开可访问的链接和信息
- 平台页面变化可能导致解析失效
- 不支持多清晰度选择、多线程加速和批量导入
- 不绕过登录、付费、地区或版权限制
