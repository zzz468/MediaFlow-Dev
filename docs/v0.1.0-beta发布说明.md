# MediaFlow v0.1.0-beta 发布说明

## 发布定位

这是 MediaFlow 的首个免费公开测试版本，用于验证 Windows 端媒体解析、下载队列、本地持久化和基础 UI。项目不依赖自建服务器、付费 API 或商业服务。

## 主要功能

- Bilibili、抖音公开链接识别与媒体信息展示
- 多任务顺序下载队列
- 暂停、继续、删除和失败重试
- HTTP Range 断点续传
- 下载历史和设置本地恢复
- 自定义下载目录
- 本地日志、缓存清理和应用内完成提示
- 关于页面和 Apache-2.0 开源协议

## Windows 安装

1. 下载 `MediaFlow-v0.1.0-beta-windows-x64.zip`。
2. 校验同名 `.sha256` 文件中的 SHA256（可选）。
3. 完整解压压缩包，不要只运行压缩包内的 EXE。
4. 运行 `MediaFlow.exe`。
5. 如果提示缺少 MSVC 运行库，请安装免费的 Microsoft Visual C++ Redistributable 2015-2022 x64。

压缩包内包含程序运行目录、`README.md`、`LICENSE`、`USER_GUIDE.md` 和 `RELEASE_INFO.txt`。

## Android 安装准备

Android APK 尚需在本机安装最小 Android SDK 后构建：

```powershell
powershell -ExecutionPolicy Bypass -File tool\release\build_android_apk.ps1
adb install -r dist\MediaFlow-v0.1.0-beta-android.apk
```

不需要 Android Studio、模拟器或 System Image。使用真实 Android 手机开启开发者选项和 USB 调试即可。

## 已知限制

- 仅支持平台公开可访问的链接和信息
- 平台页面变化可能导致解析失效
- Bilibili/抖音真实分享链接仍需发布前人工抽样测试
- 不支持多清晰度选择、多线程加速和批量导入
- 不绕过登录、付费、地区或版权限制
