# 媒体解析模块

## 设计边界

解析模块只获取公开页面可访问的媒体元数据，不下载视频文件，不绕过登录、权限、区域限制或平台安全机制。

统一流程：

1. `PlatformDetector` 根据 URL 识别平台。
2. `ParserService` 从已注册解析器中选择实现。
3. 平台解析器通过 `NetworkClient` 请求公开信息。
4. 解析器返回统一的 `ParserResult` 和 `VideoInfo`。
5. UI 只展示统一模型，不依赖平台实现。

## Bilibili

`BilibiliParser` 支持普通视频链接及 `b23.tv`、`bili2233.cn` 短链接。短链接先解析最终地址，再根据 BV/AV 编号请求公开视频信息，映射标题、作者、封面、时长、简介和平台元数据。

## 抖音

`DouyinParser` 跟随分享链接重定向，并按以下顺序合并公开元数据：

1. 页面内嵌作品数据
2. JSON-LD `VideoObject`
3. Open Graph 元数据

页面结构可能由平台调整，因此每种提取方式保持独立，并通过离线 HTML 夹具测试。后续适配页面变化时，只修改抖音解析器，不修改 `ParserService` 或 UI。

## 统一错误

- `network_error`：超时、连接失败或非成功 HTTP 状态。
- `link_expired`：作品不存在、已删除或链接失效。
- `unsupported_platform`：没有已注册的平台解析器。
- `parse_failed`：页面或响应格式无法识别、必要字段缺失。

## 测试原则

自动化测试使用注入的 `NetworkClient` 和固定响应夹具，不依赖真实平台网络，避免测试不稳定。真实网络仅用于人工冒烟验证，不进入持续集成测试。
