# 设置与持久化

## 本地数据

MediaFlow 使用独立 Repository 保存本地 JSON 数据：

- `settings.json`：下载目录、下载完成通知、失败文件清理和深色模式。
- `download_history.json`：任务地址、状态、进度、文件路径、创建时间和完成时间。

文件保存在应用支持目录下的 `MediaFlow` 文件夹。Repository 接口与 JSON 实现分离，后续可以迁移到数据库而不修改 UI 和业务逻辑。

写入采用临时文件后替换目标文件的方式，降低写入中断导致数据损坏的风险。无法读取或字段损坏时会记录文件错误，并跳过无效数据。

## 下载历史恢复

应用启动后异步恢复下载历史：

- 已完成和失败任务保持原状态。
- 上次退出时仍在下载或排队的任务恢复为暂停状态。
- 用户可以手动继续恢复后的任务。
- 恢复过程会与启动期间新创建的任务合并，避免覆盖新任务。

## 设置行为

- 默认下载目录：为空时使用平台默认目录；填写自定义路径后，后续任务使用该目录。
- 下载完成提示：任务完成时在应用内显示本地 Snackbar。
- 自动清理失败文件：启用时删除失败任务的 `.part` 文件；关闭时保留以便重试续传。
- 启动恢复：可控制中断任务是否恢复为可继续状态。
- 深色模式：保存后在下次启动时恢复。
- 缓存清理：只删除本地日志和临时 `.tmp` 文件。
