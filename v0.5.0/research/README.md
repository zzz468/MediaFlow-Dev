# v0.5.0 下一阶段研究规则

状态：**计划，尚未执行下一阶段项目复核或真实平台实验。** 本阶段列出的仓库是研究候选，不等于已验证成功、近期活跃、许可证兼容或可直接复用。

## 硬性研究门槛

下一阶段必须参考已有成功项目，且不能只看 README。对每个重点项目记录：仓库与核查日期、当前关键源码文件/调用链、最近提交及维护情况、相关 Issues、明确许可证及发布影响、在隔离条件下的实际运行结果（失败也记录）、所用公开样本与环境、数据来源和失败分类。至少比较不同实现路线，不能把多个项目共用的同一底层接口算成独立成功证据。

逐项查明：是否匿名；是否要求账号登录、Cookie/session；是否依赖浏览器上下文、签名或 JS runtime；是否借助第三方服务器；Windows/Android 实现与维护成本；哪些思想、接口、算法或代码可在许可和项目边界内参考/复用。许可证未核实或不兼容时不得复制代码。任何复用需记录来源文件、原许可证、改动、attribution 与分发义务。当前阶段没有复用第三方代码。

小量、明确公开的真实样本由下一阶段单独选择，Windows/Android 分别留下证据。按“页面可见 → 目标结构与顺序 → 可下载 URL → 真实文件/MIME → 系统打开/History”逐级判定；不可从 README、HTTP 200、单条链接、PoC 成功或一端成功推导 production 可行。正常登录只在有证据且用户主动授权时作为 App 自有会话 fallback；安全验证或访问限制按根目录 `AGENTS.md` 停止。不要导入外部浏览器状态，不使用第三方解析服务器，不上传链接、媒体或凭证。

研究矩阵：[YouTube 候选](youtube-options.md) · [小红书候选](xiaohongshu-options.md)。v0.4.0 的历史结论和测试范围仅作基线，不能代替 v0.5.0 的当期双端验证。第二阶段只做有界验证和路线决策；production 接入需后续独立决定。
