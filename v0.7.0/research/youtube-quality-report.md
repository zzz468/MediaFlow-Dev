## Minimal fix

Default selection now compares highest **actual height**, then fps, then bitrate among complete playable candidates: progressive or video-only with a declared compatible audio pair. Audio-only/nonvideo fallback remains possible when no complete video exists. Resources without an assembly relationship retain existing manual single-resource behavior; a silent video no longer displaces an available progressive default. Explicit user selection is preserved. Audio selection remains highest compatible bitrate, not `.first` without sorting.

FPS is carried from the actual player format into MediaResource; dedup now includes fps and codec so distinct codec/fps candidates in the same container are not lost. Parser's within-role ordering also considers fps before container/bitrate. UI displays dimensions, fps and codec, plus a statement that the default is highest compatible quality and unsupported mux streams are not transcoded. No codec/transcode capability was added.

Modified this round: `lib/features/parser/data/youtube/youtube_parser.dart`, `lib/features/parser/domain/media_content.dart`, `lib/features/parser/presentation/media_variant_picker.dart`.
