# Redacted Douyin observation fixture

`aweme_detail.redacted.json` was derived from the allowlisted public-field
projection produced by the 2026-09-17 local anonymous Browser Observation
sample. It is not a saved response body.

Work and author identifiers and text were replaced. Every media host and path
was replaced with an `example.invalid` value. Query parameter names preserve
the observed structural variety, while every value is empty. Cookie, account,
authorization, token, device, session and non-target recommendation data are
absent. Numeric values are synthetic. Their types, media shape, field names,
nesting and the 15 quality entries remain suitable for decoder tests.
