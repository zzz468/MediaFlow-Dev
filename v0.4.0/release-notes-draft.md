# MediaFlow v0.4.0 — Release Notes 草案

## 新增

- 支持解析抖音静态图文，并选择或下载多张图片。
- Windows 与 Android 可在 MediaFlow 内使用抖音官方登录页面建立本地会话。首次解析抖音图文可能需要完成一次抖音登录或安全验证；登录状态保存在本机，后续通常可直接解析其他图文链接。
- 多图片下载任务与 History 集成，可在重启后查看已保存的任务。

## 继续支持

- 抖音视频仍支持匿名解析。
- 保留既有 Bilibili 解析与下载能力。

本版面向 Windows x64 和 Android。登录及安全验证由抖音官方页面提供，具体方式可能因账号和平台要求而异。

## 已知说明

本版本未执行 v0.3.0 正式安装到 v0.4.0 正式包的覆盖升级实测；正式签名证书已核对一致。
