# 参考项目记录模板

复制本模板为 `v0.4.0/research/<项目或路线名称>.md` 后填写。结论分别标明“源码已核实”“项目自述”“MediaFlow 独立实测”“未核实”；对外部事实附源码或文档链接、访问日期和可定位的文件位置。

| 项目 | 记录 |
| --- | --- |
| 仓库地址 / 访问日期 | 待填 |
| LICENSE / 许可证证据 / 分发义务 | 待填 |
| 最近维护状态 / 测试状况 | 待填 |
| 关键实现文件 | 待填 |
| 解决的问题与数据获取路线 | 待填 |
| 请求路径与必要参数、签名 | 待填 |
| 内容类型、图片字段、资源顺序与下载 URL 选择 | 待填 |
| 失败降级与数据结构变化处理 | 待填 |
| 登录 / Cookie / Token 是否必要 | 待填；区分代码可选与匿名实测 |
| 浏览器、平台、第三方服务器和新增依赖 | 待填 |
| Windows / Android 可行性与验证证据 | 待填 |
| iOS / macOS / Linux 的 Adapter 路径或风险 | 待填 |
| 与 MediaFlow 架构、隐私和安全边界的关系 | 待填 |
| MediaFlow 是否采用 / 不采用原因 | 待填 |
| 参考思路或复用代码、改动和 attribution | 待填 |
| 已排除路线及证据 / 未验证项 / 下一最小验证 | 待填 |

作品与资源实测另记时间、环境、公开作品 ID、目标匹配、图片数和顺序、至少两张图片的匿名 GET、MIME、实际文件结果与 URL 时效；不要提交含用户凭据、会话数据或完整临时媒体 URL 的日志。
